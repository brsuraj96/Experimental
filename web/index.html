API Documentation

Explore the available API endpoints for the Puzzle World platform:

GET /api/db/status - Check database connection

GET /api/user - Get current user information

GET /api/progress?userId=1 - Get game progress

POST /api/progress/update - Update game progress

POST /api/session/add - Add a new game session

WebSocket /ws - Real-time game updates
