Puzzle World

A multi-game puzzle platform built with React Native

Project Overview

Puzzle World is a collection of brain-teasing puzzle games with multiple difficulty levels, progress tracking, and real-time multiplayer interactions.

Built with React Native for cross-platform compatibility, with a focus on performance and responsive design.

Technical Features

  • React Native frontend with web compatibility
  • Node.js/Express backend
  • PostgreSQL database for user data
  • WebSocket for real-time game updates
  • Responsive design for various screen sizes
  • Dark mode and customizable themes

Access the Application

Puzzle World is primarily a mobile app, but you can access some features through the web interface.

API Endpoints

GET /api/db/status

Check database connection status

GET /api/user

Get current user information

GET /api/progress?userId=1

Get game progress for a specific user

POST /api/progress/update

Update game progress for a user

POST /api/session/add

Add new game session record
